### 본문 핵심
> * 캐스팅은 컴파일러도 개발자도 의도를 알 수 없기 때문에 캐스팅을 되도록 피해라.
> * 고전 c 방식 캐스트 보다 C++ 스타일의 캐스트를 선호해라
>
> **static_cast<T>()** 
> **const_cast<T>()** 
> **dynamic_cast<T>()**
> **reinterpret_cast<T>()**
>
> * 파생 클래스 포인터를 기본 클래스 포인터로 캐스팅하면 주소값이 같을 거 같지만 같지 않을 때도 있음. 이런 경우 포인터의 offset를 구하는 동작이 런타임에 일어남 --> 캐스팅을 컴파일 타임에 끝나는 공짜가 아님(런타임에 실행될 수도 잇음)
> * 상위 클래스 함수 호출시 캐스팅 사용 --> 버그 터지니 원본을 들고가서 상위클래스 로직 실행하는 객체지향의 정석대로 해라.
