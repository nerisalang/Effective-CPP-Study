# 객체 생성 및 소멸 과정 중에는 절대로 가상 함수를 호출하지 말자
* 생성자 혹은 소멸자 안에서 가상 함수를 호출하지 마세요. 가상 함수라고 해도 지금 실행중인 생성자나 소멸자에 해당되는 클래스의 파생 클래스쪽으로는 내려가지 않습니다.

### 실습 요약
1. 부모 생성자/소멸자 안에 가상 함수를 호출했을 때 프로그램이 중단되게 되는 환경을 구축.

1. 로그를 남기거나 하는 등의 작업을 하고 싶을 때(가상 함수면 될거 같은데 싶은 상황)
2. 자식 생성자가 초기화 리스트를 통해 부모 생성자에게 데이터를 파라미터 형태로 보내게 구현함.

### 실습 결과
1. pure virtual method called, terminate called without an active exception, Aborted (core dumped)로 생성자에서 순수 가상 함수를 호출해 시스템 terminate되고 프로세스 abort되며 디버깅용 메모리 덤프 파일을 던지며 사망

1. 버그 없음. 최고의 우회법
