# 항목 23: 멤버 함수보다는 비멤버 비프렌드 함수와 더 가까워지자.
> * 멤버 함수보다는 비멤버 비프렌드 함수를 자주 쓰도록 합시다. 캡슐화 정도가 높아지고 패키징 유연성도 커지며 기능적인 확장성도 늘어납니다.

### 실습 요약
1. 클래스 내부에 private 멤버를 만질 수 있는 멤버 함수의 개수를 최소한으로 줄이는 것이 캡슐화의 진짜 의미다.
2. 따라서 멤버함수가 아닌 비멤버 비프렌드 함수를 자주 사용해라
3. 네임스페이스로 묶어 유저가 하나의 패키지 처럼 사용할 수 있게 해라
4. 헤더파일을 잘게 쪼개 기능별로 조각내라
