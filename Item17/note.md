# 항목 17: new로 생성한 객체를 스마트 포인터에 저장하는 코드는 별도의 한 문자으로 만들어라
* new로 생성한 객체를 스마트 포인터로 넣는 코드는 별도의 한 문장으로 만듭시다. 이것이 안 되어 있으면 예외가 발생될 때 디버깅하기 힘든 자원 누출이 초래될 수 있습니다.

### 실습 요약
1. 위험한 한 줄 호출 방식 (컴파일러가 실제 런타임 순서를 지 맘대로 함)
2. 안전한 독립된 문장 방식
3. 현대 c++ (make\_shared, make\_unique)
4. 1케이스 미정의 동작 보일 가능성 존재 2, 3 안전한 방식이긴함

### 실습 결과
1. 걍 자원 관리 객체는 독립된 문장으로 분리해라 
2. new로 생성한 객체를 스마트 포인터로 넣는 코드는 별도의 한 문자으로 만듭시다.
